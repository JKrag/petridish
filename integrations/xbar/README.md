# Menu bar (xbar / SwiftBar)

A compact live view of the fleet in the macOS menu bar: `🧫 working/total`, with
running sessions at the top of the dropdown and the rest grouped by bucket.
Clicking a project opens its directory.

## Setup

Install [xbar](https://xbarapp.com) (or SwiftBar), then:

```sh
petridish install
```

That writes the plugin into xbar's plugin directory and makes it executable.
Refresh xbar, or wait 30 seconds, and it appears.

For SwiftBar — whose plugin directory is user-configured and cannot be guessed —
point the installer at it:

```sh
petridish install --menubar-plugins-dir ~/Library/Application\ Support/SwiftBar/plugins
```

Don't want it at all:

```sh
petridish install --no-menubar-plugin
```

## What gets installed

A generated shell wrapper, `petridish_menubar.30s.sh`. The `.30s` is xbar's
refresh-interval convention — it re-runs the plugin every 30 seconds.

There is deliberately **no plugin source file in this directory**. The wrapper is
generated by `petridish install` because it has to embed an *absolute* path to
the `petridish` binary: xbar is launched by the GUI session, inherits launchd's
environment rather than a shell's, and never sources `.zshrc`, so neither
`~/.cargo/bin` nor `/opt/homebrew/bin` is reliably on its `PATH`. A hand-written
plugin calling `petridish menubar` would work when you tested it in a terminal
and show nothing in the menu bar.

The template it is generated from lives at
`petridish-cli/resources/petridish_menubar.30s.sh`, compiled into the binary via
`include_str!`.

## Rendering it yourself

The plugin is a thin wrapper around one command, so you can see exactly what it
will print:

```sh
petridish menubar
petridish menubar --state ./fixtures/loaded.json   # against a fixture
```

It always exits 0 and always prints something. xbar disables a plugin that
errors, so a missing or unreadable `projects.json` degrades to a visible
placeholder rather than a silent disappearance.

## Troubleshooting

`petridish doctor` reports whether the plugin is installed and executable, along
with the rest of the install surface.
